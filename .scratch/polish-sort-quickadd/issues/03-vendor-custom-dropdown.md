# 03 — 厂商自研下拉组件

**What to build:** 把厂商控件的 datalist 组合框（看起来像浏览器历史记录下拉）替换为自研下拉组件：点击展开面板，顶部可搜索、可输入任意新厂商名（创建自定义厂商），下面列出候选项——内置厂商预设 + 当前 vault 已用过的厂商名（去重）。保留上一轮的既有能力：自定义厂商（Custom Vendor）可创建、可显示真实名称；厂商值变化（选择或输入）时按既有规则触发自动填充（匹配厂商预设则全量替换官网与端点 URL，不匹配则清空）。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 展开面板样式是"真正的下拉框"（非浏览器原生 datalist 提示框）
- [ ] 面板内可搜索过滤候选；可选择预设/已用厂商；可直接输入新厂商名创建自定义厂商
- [ ] 选中或输入厂商后，触发与现状一致的自动填充行为（预设→填官网+URL；自定义→清空）
- [ ] 编辑记录时，厂商值（含自定义厂商名）正确回显
- [ ] 键盘可用（方向键/回车/Esc）与点击外部关闭
- [ ] `npm test` 与 `vite build` 通过
