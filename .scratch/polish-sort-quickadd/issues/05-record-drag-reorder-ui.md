# 05 — 记录拖拽排序 UI

**What to build:** 列表中的记录支持拖拽调整顺序（HTML5 拖拽，无新依赖）：按住记录拖动到新位置后松开即生效，顺序通过 reorder 命令持久化到 vault。排序是全局顺序：左栏厂商/标签筛选下看到的是该全局顺序的筛选结果；切换筛选、重启应用后顺序保持不变。

**Blocked by:** 04 — 记录顺序数据模型

**Status:** ready-for-agent

- [x] 列表项可拖拽，拖到目标位置时给出视觉反馈（占位/高亮）
- [x] 松开后顺序立即更新并持久化（重启后保持）
- [x] 筛选（厂商/标签/搜索）下的记录仍按全局顺序展示；拖拽仅在未筛选时可用（或筛选时禁用拖拽）
- [x] 拖拽不触发记录选中/打开等既有点击行为
- [x] `npm test` 与 `vite build` 通过
