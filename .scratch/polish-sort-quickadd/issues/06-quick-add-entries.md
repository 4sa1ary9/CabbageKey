# 06 — 快速新增入口

**What to build:** 两个快速新增入口：

1. 筛选态新增：左栏选中某个厂商后点"+ 新增"，新增表单自动填好该厂商，且厂商匹配预设时同步填好预设官网与端点 URL（与手动选择厂商行为一致）；不匹配预设的自定义厂商则只填厂商名。
2. 复制新增：详情面板操作区新增"复制"按钮（位于编辑/删除旁），点击复制当前记录的全部字段（用途名称、api_key、厂商、端点 URL、官网、标签、备注）并打开新增表单，名称改为 `原名_copy`，用户只改需要改的字段即可保存。

**Blocked by:** 03 — 厂商自研下拉组件

**Status:** ready-for-agent

- [ ] 选中厂商筛选后点"+ 新增"：表单厂商值正确（新组件 API 设置），预设厂商同时带出官网+URL，自定义厂商仅带厂商名
- [ ] 详情面板有"复制"按钮；点击后新增表单打开，全部字段预填、名称=`原名_copy`
- [ ] 复制出的记录保存后与源记录字段一致（除名称后缀）
- [ ] 多次复制同名记录时后缀可重复（不强制唯一）
- [ ] `npm test` 与 `vite build` 通过
