# 09 — 切换厂商静默清空端点 URL 无提示

> *This was generated by AI during triage.*

**Category:** enhancement

**Status:** done

## Triage Notes

**现象：**
厂商值变化触发自动填充的规则是"全量替换"：切到预设厂商 → 官网与端点 URL 整体换成预设值；切到非预设（自定义）名 → 官网与 URL 全部清空。这是 CONTEXT.md 写明的设计，但破坏性强且不可撤销：用户给一条记录手工配好了 URL，编辑时改了个厂商名，已填 URL 无声消失，保存后才察觉。

**建议方案（任选其一，倾向 a）：**
a. 表单内有用户已填/已回填的端点 URL、且本次厂商切换会清掉它们时，弹一次确认（或 toast 说明"已清除 2 个端点 URL，可撤销"级别提示）；
b. 切换到自定义厂商时保留已填 URL 不清空，仅切换预设厂商时才全量替换——语义变化较大，需先对齐 CONTEXT.md 的术语定义。

**待维护者定夺：**
- 选 a 还是 b（b 需要同步改 CONTEXT.md 的"厂商预设"词条）
- 提示的具体形态（确认框 vs 可撤销 toast）
