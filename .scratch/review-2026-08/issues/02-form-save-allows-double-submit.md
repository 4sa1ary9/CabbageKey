## Agent Brief

**Category:** bug
**Summary:** 保存命令在途时应阻断再次提交，防止双击产生两条重复记录。

**Current behavior:**
表单提交处理器在 await 后端命令（add_record / update_record）返回前不阻止再次提交。保存按钮连点两次会发出两次新增命令，各自成功落盘，产生两条内容相同的记录。

**Desired behavior:**
提交开始即进入"在途"状态（保存按钮禁用 + 可见禁用样式），命令返回（成功或失败）后恢复。成功时对话框照常关闭；失败时错误照常显示在表单错误区并恢复按钮。在途期间重复触发的 submit 事件一律忽略（Enter 也会触发 submit，不能只依赖按钮 disabled）。

**Key interfaces:**
- 表单 submit 处理器：现有"校验 → invoke → 应用视图/关闭"流程保持不变，仅加在途守卫。
- 下次打开表单时在途状态必须已复位（无论上次成败）。

**Acceptance criteria:**
- [ ] 在途期间再次点击保存或按 Enter 不发出第二个命令
- [ ] 保存成功后按钮状态不残留，下次打开表单可正常保存
- [ ] 保存失败后按钮恢复可用，错误信息照常显示
- [x] vitest 全绿

**Out of scope:**
- 其它按钮的防抖（删除已有模态确认挡着）
- 请求超时/取消机制
