## Triage Notes

**现象：**
vault 落盘走"临时文件 + 原子改名"，防崩溃半截文件；而应用配置（last_path + vault 历史，与启动自动打开直接相关）的保存是直接整文件覆写。写盘中途崩溃/断电会留下损坏的 config——现有加载逻辑对损坏 config 静默按空处理，后果是历史丢失 + 不再自动打开，可自愈但无谓。

**建议方案：**
配置保存复用 vault 已有的原子写路径（同一临时文件+改名策略）。改动极小。

**待维护者定夺：**
- 直接认可则可升 ready-for-agent（规格已完整：行为不变，仅写盘方式原子化）
