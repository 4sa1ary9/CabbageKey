# 07 — 详情面板不展示 created_at / updated_at

> *This was generated by AI during triage.*

**Category:** enhancement

**Status:** done

## Triage Notes

**现象：**
记录数据模型一直携带 created_at / updated_at（ISO UTC 字符串，增改时由后端生成），但详情面板从未展示——数据存了、零消费，属于"白背的字段"。

**建议方案：**
详情面板底部（或标题下方小字）展示"创建于 / 更新于"。注意值为 UTC，展示时转本地时间或保留 ISO 但标注 Z，二选一即可；老 vault 若时间戳为空则不显示该行。

**待维护者定夺：**
- 放置位置与格式（本地化时间 vs ISO 原样）
- 是否需要（如果维护者认为时间戳无用，也可以反过来把字段从 schema 中去掉——但 golden test 冻结了格式，去字段的代价更大，倾向展示）
