# 08 — api_key 显示后不自动重新掩码

> *This was generated by AI during triage.*

**Category:** enhancement

**Status:** done

## Triage Notes

**现象：**
详情面板的"显示"按钮把 api_key 从掩码切到明文后，明文一直保留到用户切换选中项或触发重渲染为止。复制路径已有 30 秒自动清空剪贴板的防护，显示路径却没有对称的时效控制——屏幕上的明文是更长的暴露窗口。

**建议方案：**
显示后 N 秒（15–30，与剪贴板策略对齐取 30）自动回到掩码态；用户再次点"显示"重新计时。实现上只需一个与现有 toast/clear 同型的定时器，注意切换选中记录时清掉定时器。

**待维护者定夺：**
- 是否要这个自动回掩码（有人偏好常显直到手动隐藏）
- 时长取值
