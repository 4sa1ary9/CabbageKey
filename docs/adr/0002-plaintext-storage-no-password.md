# 放弃主密码加密，改为明文本地存储

2026-08-03，用户确认：不需要网盘多设备同步、不需要任何密码，但要求支持迁移（拷贝整个文件夹到新机器即可用）。免密 + 可迁移与加密根本矛盾——加密密钥派生自主密码，没有密码就没有能随数据走的密钥；机器绑定密钥（DPAPI 等）则无法迁移。**决定：vault 改为明文 JSON 文件；删除整个加密层（Argon2id/AES-256-GCM/KAT）、锁屏三模式、"记住我/免密"登录与 config.json 凭据、为网盘同步设计的 sha256 冲突检测与 .bak。** 安全姿态与 `~/.aws/credentials`、`~/.ssh` 明文私钥相同，由本机账户密码/BitLocker 兜底。旧加密 vault 由一次性迁移脚本（用完即弃）解锁导出为新格式，新应用不含任何加密代码。

## Consequences

- API key 明文落盘：任何能读硬盘的程序/人/备份软件都可取得 key 原文。这是用户知情接受的威胁模型。
- README、DESIGN.md、HANDOFF.md 中"本地加密""丢网盘同步"的描述全部过时，需随实现更新。
- 打开应用直进主界面，启动路径上不再有锁屏与密码校验。
