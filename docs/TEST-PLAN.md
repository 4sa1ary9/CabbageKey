## Affected Pages/Routes
- 首次运行/解锁界面 — 设主密码、创建库；错误主密码要给清晰报错可重试
- 主界面(搜索列表+详情面板) — 搜索、按厂商分组、按标签筛选、字段级一键复制
- 录入/编辑表单 — 用途名称+api_key 必填校验；厂商/url/备注/标签可空
- 导出/备份 — 明文导出(高风险，需二次确认)、保存前自动留旧版副本

## Key Interactions to Verify
- 解锁→搜索→复制 api_key / 复制 url（各自独立）
- 新增记录→重开 app→数据仍在（持久化）
- 复制后剪贴板自动清空发生在粘贴窗口之后，不能早于用户粘贴
- 编辑/删除按 id 只影响单条；重名用途两条都在、id 不同

## Edge Cases
- 错误主密码→清晰报错、不崩溃、可重试
- 篡改后的密文→GCM 认证拒绝，不静默接受
- 空库、搜索无结果→空状态正常渲染
- 厂商为空的记录在分组浏览里如何归类
- 保存前文件被别的设备改过(哈希变化)→弹警告，不静默覆盖(D4)

## Critical Paths
- [CRITICAL] 加密 round-trip + KAT 固定向量：升级若改了 KDF 参数/编码导致老库解不开，测试要立刻红(D5)
- [CRITICAL] 错误密钥→解密干净失败(无 panic、无半成品)
- [CRITICAL] 必填校验→缺用途或缺 key 被拒
- [CRITICAL] 冲突检测→文件在编辑期间被改过，保存时警告不静默覆盖
- [CRITICAL] 主密码丢失→明确不可恢复(测试:乱密码永远解不开)；明文导出+本地备份作为逃生口(D6)
