# Test Plan

> 2026-08-04 随明文化重构更新：全部改为无密码流程（ADR-0002）。加密时代的主密码/解锁/冲突检测用例已删除。

## Affected Pages/Routes

- vault 选择页 — 打开已有 / 新建 / 历史列表（最多 10 条、失效置灰、单条移除）
- 主界面（三栏：搜索列表 + 详情面板）— 搜索、按厂商分组、按标签筛选、字段级一键复制
- 录入/编辑表单 — 用途名称 + api_key 必填校验；厂商 / 端点 URL / 官网 / 备注 / 标签可空
- vault 文件 — 明文 JSON，人类可读；迁移 = 拷贝文件/文件夹直接打开使用

## Key Interactions to Verify

- 启动：上次 vault 存在 → 直进主界面，全程无密码；不存在 → 选择页并提示"文件不存在"
- 增 → 搜 → 复制 api_key / 复制 url（各自独立）→ 改 → 删，全流程无密码
- 新增记录 → 重开 app → 数据仍在（明文落盘持久化）
- 编辑/删除按 id 只影响单条；重名用途两条都在、id 不同
- 复制后剪贴板自动清空发生在粘贴窗口之后，不能早于用户粘贴（30 秒倒计时可见）；且仅当剪贴板仍是本应用复制的值才清空（期间用户在别处复制了新内容则不动）
- 切换 vault：主界面入口 → 关闭当前 → 选择页 → 打开另一个 / 新建

## Edge Cases

- 启动时 last_path 指向的文件被删/移 → 选择页顶部明确提示，可重选或新建
- vault 文件损坏 / 不是合法 JSON → 干净报错，不崩溃
- 空库、搜索无结果 → 空状态正常渲染（首次引导 vs 清除筛选）
- 厂商为空的记录归入左栏"未分组"项（确有无厂商记录时出现；可筛选；无拖拽手柄、不参与厂商排序持久化）
- 历史列表：文件不存在的条目置灰 + "文件不存在"标签；× 可移除；移除的恰是 last_path 时下次启动不再自动打开

## Critical Paths

- [CRITICAL] 明文格式 golden test：磁盘 JSON 形状（schema_version 1）冻结，改动立即红——接替原 KAT"防静默改格式"的角色
- [CRITICAL] 必填校验 → 缺用途或缺 key 被拒
- [CRITICAL] 原子写 → 保存时崩溃不留半截文件
- [CRITICAL] 迁移 → 拷贝整个数据文件夹到另一路径/另一台机器直接打开使用，数据一致
- [CRITICAL] 威胁模型 → vault 是明文：不放入网盘同步目录（CHANGELOG 0.3.0 有明确说明）

## 人工端到端走查清单（发布前必过）

> 无密码主流程（对应 spec 的"不引入 DOM/E2E 自动化测试，维持人工走查传统"）。

- [ ] 启动应用：有上次 vault 时**直进主界面**，无任何密码输入框
- [ ] 新增：点 "+ 新增"，只填用途名称 + api_key 即可保存；缺必填被拒
- [ ] 搜索：输入关键字能即时过滤到刚新增的记录
- [ ] 复制：点复制 api_key，按钮变"✓ 已复制"、出现"× 秒后自动清空"提示
- [ ] 修改：编辑该记录改个字段，保存后详情面板与 vault 文件都更新
- [ ] 删除：删除该记录，列表与 vault 文件都移除
- [ ] 拖拽排序：拖动记录到新位置，顺序立即更新、拖动中目标位有占位反馈；重启 app 后顺序保持；筛选/搜索状态下仍可拖拽，组内末尾落点自动修正为全局顺序下一位
- [ ] 搜索：api_key 片段 / 端点 URL 域名也能搜到对应记录；左栏"未分组"可筛选无厂商记录
- [ ] 详情：显示创建/更新时间；api_key 显示 30 秒后自动回掩码
- [ ] 表单守卫：已有端点 URL 时改厂商弹确认、取消回退；Esc/点外部关闭时有未保存修改先确认；保存期间按钮禁用
- [ ] 窗口：缩到最小宽度（860px）时详情面板与复制/编辑/删除仍可用
- [ ] 单实例：重复启动 exe 只聚焦已有窗口，不出第二份界面
- [ ] 迁移：把整个数据文件夹拷到另一路径，从选择页"打开已有"打开拷贝出的 vault，数据完整可用
